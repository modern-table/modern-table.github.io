# Modern Table: instructions for Claude sessions working in this repo

Repository `modern-table/modern-table.github.io` (the `modern-table` GitHub organization). The game is served by GitHub Pages from `main` at the repo root as https://modern-table.github.io/, so whatever `index.html` is on `main` is what players get. Moved here on 2026-10-17 from an older address, which now only forwards players here and carries their saved decks over (`#import=` in the URL, read by `IMPORTED` in both pages). Keep the project's public face free of personal names: commits are authored by Claude, and nothing in the repo, the pages or the README should name the maintainer.

## Layout
- `src/app.src.html`: game source (single page; placeholders `/*__DECKS__*/[]` and `/*__PEERJS__*/` are filled by the build).
- `src/decks.txt`: built-in decklists (format below).
- `src/peerjs.min.js`: vendored PeerJS.
- `src/cards.json`: Scryfall data for every card in `src/decks.txt` (plus the tokens they make, keyed `id:<scryfall id>`), built into `index.html` as `BAKED` so the tournament decks need no Scryfall lookups (since v3.42). Written by `tools/make_cards.py <oracle-cards.json>` from Scryfall's Oracle Cards bulk file. The sandbox cannot reach Scryfall, so don't write it by hand: the **Build card data** workflow (`.github/workflows/cards.yml`) regenerates it, rebuilds and pushes whenever `src/decks.txt` changes, every day at 13:23 UTC (retrying when Scryfall answers 5xx), and on "Run workflow". Its commits are by github-actions[bot]. Cards missing from it (new decks before the workflow has run, pasted decks) are still looked up at runtime. The workflow's notice lists names it could not find: a card a decklist calls by another name (Arena's "Through the Omenpaths" names for Marvel cards, e.g. Kavaero, Mind-Bitten = Superior Spider-Man) goes in `src/aliases.txt`, and the game also reads that file for pasted decks. Cards from decks we paste and play (not tournament lists) can be listed in `src/extra.txt` (decklist format); the workflow builds them in too.
- `build.py`: `python3 build.py` writes `index.html`. It drops any deck with fewer than 60 main or more than 15 sideboard cards and refuses to build with fewer than 10 valid decks.
- `index.html`: generated. Never hand-edit; always rebuild and commit it together with the `src/` change.
- **Line comments end the line.** Much of the source is long one-line statements with trailing `// …` notes. When inserting code into such a line, put it before the `//`, never after: anything after a `//` is part of the comment and silently never runs (v4.37 disabled the city's blessing this way; found in v4.55). `build.py` prints `WARNING: … code after a // comment never runs` for lines that look like this; treat any such warning as a bug.
- `src/draft.src.html` → `draft/index.html`: the Draft Table (see below). Also generated by `build.py`.
- `draft/sets/*.json`, `tools/make_draft_sets.py`: booster odds per set for the Draft Table.

## Versioning
`const VERSION = 'v4.NN'` in `src/app.src.html` (v4.0 on 2026-10-21: the table runs the match, with game losses, a round clock, a sideboarding timer and end-of-round turns; v3.0 on 2026-10-15 brought auto-pay from the mana pool, v3 ran to v3.78; v2.0 on 2026-10-14 marked the table resolving rules itself, v2 ran to v2.06; v1 ran to v1.99). Bump NN by one for any feature or behaviour change: v4.0 → v4.01 → v4.02 … Do NOT bump it for a decks-only refresh.

With every version bump, add one line at the top of the `NEWS` array in `src/app.src.html` (`['v4.NN','Mon D','what changed']`). It feeds the "What's new" list on the front page and in the table menu, and is written for players: plain language, no function names.

## Draft Table (`/draft/`)
Booster draft for up to 8 players; bots fill empty seats. Its own version: `const VERSION = 'v0.NN'` in `src/draft.src.html`, bumped the same way.
- **Hub model:** the host's browser holds the whole draft (`H`), generates every pack and sends each player only their own view (`V`: current pack, picks, pod status, tournament). Guests send `join`, `pick`, `ready`, `result`. Host state is saved in localStorage (`dt_host`) so a reload resumes; guests rejoin their seat by a stored player id (`dt_pid`).
- **Pack odds:** `draft/sets/<set>.json`, generated by `python3 tools/make_draft_sets.py /path/to/sealed_basic_data.json` from https://github.com/taw/magic-sealed-data (weighted pack layouts and sheets; cards are `set:collector_number`, `:foil` suffix for foils). To add a set, add its booster code to `SETS` in that script, rerun it, rebuild. Sets whose draft works differently (Commander Legends, Conspiracy, Unstable, Mystery Booster) are deliberately left out.
- **Cubes:** a pasted cube list goes, cleaned to one card name per line, in `draft/cubes/<code>.txt`; `python3 tools/make_cube.py <code> "Name" draft/cubes/<code>.txt` writes `draft/sets/<code>.json` (`cube:1`, `names`) and lists it under "Cubes" in `index.json` (`make_draft_sets.py` keeps those entries). A cube is shuffled once per draft and dealt in packs of 15 without repeats; cards are looked up by name (ids `n|Card Name`); names Scryfall can't find are left out and the host sees a notice. Bots ignore rarity in a cube.
- **Offered sets (v0.13):** the set picker shows only the codes in `READY` near the top of `src/draft.src.html` (Reality Fracture, Final Fantasy, MH2, MH1, Khans and the DF07 cube: the ones whose cards the Modern Table plays fully). The other set files stay in `draft/sets/` and `index.json`; add a code to `READY` when its cards are done.
- **Cards:** fetched from Scryfall `/cards/collection` by set and collector number, cached per set in `dt_cards`.
- **Hand-off to the Modern Table:** the deck is saved into the shared `mt_decks` list as text lines `N Card Name [id:<scryfall id>]`; `parseDeck` in `src/app.src.html` reads that suffix so the exact printing is used in play. Match links are `../?t=CODE&r=h|g&d=1` (open or join that table and show the newest saved deck); `?r=s&d=1` is practice. Both pages must stay on the same site so they share browser storage.
- **PeerJS** is loaded from `../src/peerjs.min.js`, not inlined, to keep the page small.
- **Testing:** needs a local PeerServer (`npm i peer`, `PeerServer({port:9000, path:'/', host:'127.0.0.1'})`), the repo served over http, and `?peerhost=127.0.0.1:9000&peersecure=0`. Mock `api.scryfall.com/cards/collection`. Drive a host and two guests through draft, deck building and three rounds; `window.__D` exposes `H`, `V`, `genPack`, `loadSet`.

## decks.txt format
```
# comment lines start with #
@@ Event name|YYYY-MM-DD|tournament id|place|Archetype|Pilot|deck id
4 Card Name
...
Sideboard
2 Card Name
```
One `N Card Name` per line, exact card names, split cards as `Wear // Tear`. No `Deck`/`Companion` label lines (a companion is already in the sideboard). No `|` inside a field. Place is `1st`, `2nd`, ...

## Weekly deck refresh (what the Monday scheduled task does)
Goal: replace `src/decks.txt` with top finishers from Modern events of the last 14 days on MTGGoldfish, rebuild, commit, push to `main`.
1. Search: WebFetch `https://www.mtggoldfish.com/tournament_searches/create?tournament_search%5Bname%5D=&tournament_search%5Bformat%5D=modern&tournament_search%5Bdate_range%5D=MM%2FDD%2FYYYY+-+MM%2FDD%2FYYYY&commit=Search` (14 days ago to today). First page only.
2. Pick up to 6 events, newest first: Challenges, Super Qualifiers, Showcases, large paper events. Skip Leagues.
3. For each, WebFetch `https://www.mtggoldfish.com/tournament/ID` for the first 8 rows: place, deck name, pilot, deck id.
4. Choose at most 36 decks: every distinct archetype once first (highest finish), then remaining top-4 finishers.
5. Fetch lists from `https://www.mtggoldfish.com/deck/arena_download/DECKID` (`/deck/download/` is robots-blocked; `/deck/ID` has no list in its HTML). ONE AT A TIME, never in parallel, at most 4 per turn. On HTTP 429 do not retry that page; stop fetching after the second refusal and use what you have. The shell cannot reach mtggoldfish; only WebFetch can.
6. Keep decks from the existing `src/decks.txt` that are still within the last 14 days and were not re-fetched, so a rate-limited week does not shrink the list. Drop decks older than 14 days only if at least 20 decks remain without them.
7. Write `src/decks.txt`, run `python3 build.py`, check its last line reports at least 10 decks and none unexpectedly dropped.
8. Commit `src/decks.txt` and `index.html` (the Build card data workflow then adds the new decks' cards to `src/cards.json` and rebuilds by itself, a few minutes after the push) with message `Weekly deck refresh YYYY-MM-DD (N decks)` and push to `main`. If the push is refused, do not try other routes; report it.
Colour-code archetype names from MTGGoldfish (WU, UR, WBG) may be replaced with a plain name only when the list makes it obvious.

## Auto-pay (v3.0)
With `S.autoPay` on (the default; ☰ menu toggle), `castSpellNow` and `activate` work out the cost (`castSyms`/`abilSyms`), plan it from the pool (`payPlan`) and either pay at once or open `#payPanel`, which waits while lands are tapped; the card stays in its zone until paid. Alternative costs pass `payCost` (warp, dash, flashback, madness, bestow, harmonize with `less`, Mystical Dispute), `castAlt` pays first, free casts pass `nm`. Mana with a restriction or rider goes to `G.me.smana` (its own row under the pool) and is spent only where `specRule` allows. Old tests that cast by hand should set `S.autoPay=false` after the page loads.

## Scryfall requests
Scryfall allows 2 card lookups a second (`/cards/collection`, `/cards/named`, `/cards/search`) and locks a client out for 30 s after a 429 (https://scryfall.com/docs/api/rate-limits). Every request goes through `sfetch` (both pages): one queue, 0.55 s apart, 15 s timeout, 31 s pause and one retry after a 429. Never call `fetch` on api.scryfall.com directly. Images (`cards.scryfall.io`) have no limit.

## Testing
Add `&nobake` to the URL in tests that mock Scryfall, so the built-in card data does not replace the mock's cards.
The page needs Scryfall and a PeerJS broker at runtime, which the cloud sandbox cannot reach. For a smoke test, load `index.html` in the pre-installed Chromium with Playwright, mock `api.scryfall.com/cards/collection`, and check the deck screen lists the decks and a solo game starts.

## The match (v4.0)
A game is lost at 0 or less life, 10 poison or a draw from an empty library: the losing player's client notices it (`lossCheck` from `changed()` and `draw()`), and both get the game-over window (`G.go`; messages `gameover`, `goready`, `goback`). The win is recorded only when both click Begin sideboarding. The round clock (`G.mt`) is kept by the host (p1) and sent as `mt`; the guest asks with `mtreq`. It starts at 50:00 once both players have a deck (`deckReady`), keeps running through sideboarding (3:00, `G.sbEnd`), and at 0 offers the end-of-round turns (turn 0 + five, `#turnSign`), then asks who won. Two-player tables only.

## Several targets (v4.04)
An ability with two or more "target" phrases (`tgtPhrases`, `tgtSlots`: Awaken the Inferno, Savage Punch, Practiced Offense) is targeted one phrase at a time: each arrow carries its phrase number (`a.s`), `G.mode.slot` drives the hint and dimming (`tgtSpec(c, slot)`), Esc moves to the next phrase (`tgtNextSlot`). In `simpleEffects` each sentence gets only its own phrases' targets (`SLT`; a sentence without a phrase keeps the previous one's, `slIt` is the one before for "it fights"). Abilities with one phrase, graveyard-card targets, unchosen split halves, "instead" re-statements and hand-drawn arrows (no `a.s`) keep the old behaviour: all arrows for every sentence. When adding a handler that reads `tg`, assume it holds this sentence's targets.

## Asking the opponent (v4.07)
When an effect makes the other player choose (Fact or Fiction's piles, Intuition, Karn's +1, Council's Judgment's vote), `askOpp(q, fallback)` sends `{t:'q', rid, q}` and waits for `{t:'qa', rid, v}`; the other client runs `answerQ` (a pick box on their screen). `oppChooses(by, title, cards)` wraps the one-card case. Without an opponent (practice) the caster chooses. Effects every player does at once still go through `eachDo` ops plus an `each` message (add new ops to the whitelist in the message handler). Inside `simpleEffects`, a handler that does several sentences at once pushes the later ones onto `skipS` so they are not run again.

## Draft sets (v4.12)
At the top of the `simpleEffects` sentence loop: mode and ability-word labels ("Item — ", "Raid — ") are stripped, except labels older handlers read whole (Landfall, Delirium, Revolt, Threshold, … see the list there) and sentences matching `keepS`; "for each opponent, … target …" loses its opening; simple conditions are judged (`cnd`: attacked this turn, ferocious, hellbent, kicked, N or more creatures, discarded this turn, N or more cards in graveyard) so the rest of the sentence runs or is skipped; "… instead" applies only the difference from the sentence before (`LASTPUMP` for pumps, the text's first "You gain N life" / "deals N damage"). `xNum(phrase)` and `condTrue(phrase)` return null when the table can't work something out (then the sentence is left, or the player is asked). Morph (`morphOf`, `morphCast`, `morphUp`), suspend (`suspendOf`, `suspendCard`, `suspendTick`), outlast (in `abilitiesOf`), living weapon (enter trigger), modular (in `diesTrig`) and changeling (`NOTCT` in `matchesDesc`) are keyword-driven.

## Draft sets, the long tail (v4.16)
- **"This way" and "that creature":** `move()` appends to `ZLOG` (`{c, from, to, at}`, counter `ZSEQ`). Inside `simpleEffects`, `since(to, from)` lists the cards this effect has moved so far (Chrome Courier's "if you put an artifact card into your hand this way", Discerning Taste, Terra's "milled this way"). `tgSnap[id]` holds each target as it was before the effect (counters, attacking, type line, mana value, remaining toughness or loyalty): Bring Low, Rite of the Serpent, Prophesied End, Flay Essence, Violent Echoes.
- **A resolving spell's effects get a fresh object** (`autoResolve({…})` in `resolve`), and the card itself has already gone to the graveyard. Anything a handler reads from the spell must be copied there: `cgy` (cast from a graveyard), `sacTp` (type of the sacrificed permanent, also `G.sacTp`), `ovl`, `md`, `k0`.
- Flags: `c.cgy` (on the stack and the battlefield), `c.egy` (entered from a graveyard this turn), `c.pcE` (colours spent, kept on the permanent), `m.mill` (cards milled this turn; published), `m.nt` (`gk` Garruk / `jc` Jace until-your-next-turn attack effects; published, applied in `attack()`), `c.ntkw` (keywords until your next turn, read by `grantedKw`), `c.ntb` (a pump until the controller's next turn, re-applied by `clearBoosts`), `m.howl`, `m.mtnR`, `c.lyraT`, `m.gwT` (Gaea's Will), `c.sacUp` (sacrificed at the next upkeep, `upkSacTick`), `c.dieTx` (a granted dies trigger, `diesTrig`), `c.impC` (Dermotaxi's imprinted card), `c.hid` (hideaway).
- **The opponent's library:** `askOpp({kind:'libtop', n, exile})` answers with their top cards; `libtake` puts one onto the asker's battlefield and the rest on the bottom (or shuffles); a `yield` with `zone:'ex', pl:1` hands an exiled card over to be cast free this turn. Other new answers: `yn`, `ctype`. New messages: `exlib`, `pbid`, `suspendme`, `peekfd`. New `mod` fields: `exd`, `corr`, `ntt`.
- `abilLess(c, a)` takes "This ability costs {1} less to activate for each …" off an activated ability. `altCostSpec` reads "sacrifice a Mountain" and Mogg Salvage-style free casts; `fbExtra` reads "Flashback—Tap three untapped white creatures you control".

## The practice opponent (v4.17)
In a practice game (`G.solo`), and after "Skip the roll (practice alone)" at a table nobody has joined, `G.opp` is a dummy player named Practice kept on this page (`G.opp.dummy`, `newDummy()`, saved in the session as `dum`). `send()` hands every message to `dummyRoute`: the types in `DUMMY_OK` run through the normal `onMsg` with the two sides swapped (`asDummy`: `G.me`/`G.opp`/`G.myId` exchanged, `DSW` set so `render`, `changed` and `save` do nothing), then anything Practice sent back is handled. Practice never takes a turn: `dummyRefresh()` untaps it and clears damage and boosts at the start of each of my turns; `dummyReset()` on a new game; `dummyLoss()` opens the game-over window when it reaches 0 life or 10 poison. I declare its blocks (`pblockStep`, `#blockBar` with `data-pbk`). The ⚑ Practice button (`practiceMenu`) adds vanilla `cu` permanents to its side (`dummyAdd`, `dummyCreature`). Use `vsReal()` for "a friend is at the table" (clock, pause, asking the other player) and `vsAny()` for "someone to fight" (combat steps).
Automatic triggers that need a target (Phelia, Flickerwisp: `ab.auto`) keep the target prompt up (`autoArm` from `render`) until a target is clicked or No target / Esc (`autoNone`, `ab.nt`).

## The tour (v4.27)
`TOUR_STEPS` (lobby, decks, table) drive a spotlight tour: `#tourHole` (box-shadow mask), `#tourCard` (Back / Next / Skip), `#tourBlock` (blocks clicks). `tourStart('lobby')` from the front-page link walks the front page, then opens a practice game (`begin('solo')`, clicks a tournament deck, then Play this deck) and walks the table; `tourStart('table')` from ☰ or the help page walks only the table. A step whose element is hidden is skipped. Keys: → / Enter, ←, Esc; other game keys are held off while it runs. The front-page offer (`#tourLine`, under the intro, with an × `#tourX`) shows only until `mt_toured` is set by taking the tour or closing it (v4.28).
